# Skill Exchange

Skill Exchange is a platform that connects people who want to learn new skills with those who can teach them. Users can exchange knowledge, collaborate with others, and grow together through a simple and interactive community-based system.

## Features

* User Registration and Login
* Create and Manage Skill Profiles
* Search for Skills and Users
* Skill Request and Exchange System
* Chat or Communication Feature
* Dashboard for User Activities
* Responsive and User-Friendly Design

## Technologies Used

* Android Studio
* Kotlin
* Firebase Authentication
* Firebase Realtime Database / Firestore
* XML / Jetpack Compose
* Git & GitHub

## Problem Statement

Many people want to learn new skills but cannot afford expensive courses or do not know where to find mentors. Skill Exchange solves this problem by creating a community where users can teach one skill and learn another through mutual collaboration.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/skill-exchange.git
```

2. Open the project in Android Studio.

3. Sync Gradle and install dependencies.

4. Run the application on an emulator or Android device.
